# Changelog

## 0.2.0

- Folders: create, rename, move, drag and drop and delete folders, with live updates in both directions
- Real file modification times, so saving a script that changed in the game offers Compare and Overwrite
- The explorer root is labelled `NullByte`
- The explorer refreshes by itself when the game connects, restarts or loads a save
